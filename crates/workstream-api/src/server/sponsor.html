Publication checklist

  1. Register a sponsor and create the project. For grants, register the worker first. ClaimWork and SubmitWork are separate grants.
  2. Ingest a versioned guide, then activate the same version and content digest. Policy approval requires an already compiled policy ID.
  3. Create the task under the project, screen against the active guide, then release with a reason. Check each receipt for Verified before using its outcome.
